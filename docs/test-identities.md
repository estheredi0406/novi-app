# Demo identities for testers

The identity check (ANID) is still a mock (D3). It only accepts these demo
identities, built into `apps/api/src/providers/identity/MockAnidProvider.ts`.
They are invented: every NIU starts with `0000`, so none is a real person's.
They follow the card's format, 4-3-4 digits. Each one can create a single
account, so give each tester a different line and note who has which.

In pilot mode the SMS and ANID codes appear on screen in the app; otherwise
they are in the server logs (search `mock SMS` and `mock ANID`).

After signing up, a tester can show her own first name to her groups:
*Mon compte → Nom affiché à mes groupes*. The legal name stays the demo one.
